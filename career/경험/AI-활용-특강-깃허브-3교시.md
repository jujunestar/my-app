# AI 활용 포트폴리오 특강 3교시 — 깃허브 이력 실습

## 문제
배포된 포트폴리오 페이지에 내 GitHub 주소를 연결하고, 이력이 자산이 되도록 기록을 쌓아야 했다.
사이트가 이미 배포된 상태에서 안전하게 디자인을 실험하는 방법도 필요했다.

## 과정
index.html의 연락처에 GitHub 주소를 링크로 연결하고, commit·push로 반영했다.
컴퓨터 구조 시뮬레이션 경험을 네 칸 마크다운 파일로 만들어 career/경험 폴더에 저장했다.
디자인 실험은 new-design 브랜치에서 진행하고, main에서 원래 상태를 확인한 뒤 merge로 합쳤다.

## 해결
git의 기본 동사 add·commit·push·switch·merge를 전부 손으로 실행했다.
실험은 갈래에서 하니 실패해도 main이 무사함을 직접 확인했다.

## 결과
사이트가 새 디자인(에메랄드 테마)으로 배포되었다.
3교시 완료 시점에 main 브랜치에 커밋 8개와 경험 파일이 쌓였다.
